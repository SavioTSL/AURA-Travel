Como funciona a solicitação de orçamento?

Preencha suas preferências para gerar uma mensagem. Você pode copiá-la; o envio por WhatsApp estará disponível somente quando um contato autorizado for configurado. Este site é demonstrativo e não envia solicitações automaticamente.

Posso personalizar meu roteiro?

A proposta da AURA é inspirar viagens personalizadas. Use o campo de observações para descrever interesses, ritmo de viagem e necessidades. Os roteiros apresentados são exemplos fictícios.

Os valores apresentados são reais?

Não. Todos os preços são ilustrativos e servem apenas à demonstração do projeto. Não representam uma oferta, disponibilidade ou cotação comercial.

Minha solicitação confirma uma reserva?

Não. Nenhuma reserva, pagamento ou contratação é feita neste site. A mensagem gerada é somente um rascunho para planejamento.

Meus dados ficam armazenados?

Os dados do formulário permanecem apenas nesta página e não são salvos pelo site. Somente os identificadores dos destinos favoritos são armazenados no navegador. Ao usar um serviço externo, valem também suas políticas.
